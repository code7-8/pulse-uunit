# Пульс — студенческая лента УУНИТ

Android-приложение объединяет новости университета, мероприятия и общение студентов. Пользователь выбирает темы, подписывается на авторов, видит события, на которые идут друзья, обсуждает публикации и общается в личных чатах с фотографиями.

Автор может добавить до шести фото и отправить материал на проверку. DeepSeek V4.1 Flash 1017 через OpenRouter предварительно проверяет текст и изображения, показывает результат и причину замечаний. Автор может исправить материал или запросить перепроверку человеком. Финальное решение принимает модератор; доступны возврат на доработку, повторная отправка и история решений.

Основная сборка использует общий сервер с HTTPS и автоматически обнаруживает изменение адреса. Автономная демосборка работает без интернета, содержит готовые примеры и сохраняет действия на телефоне. Начальное оформление использует палитру УУНИТ; доступны другие цвета и тёмная тема.

Технологии: Flutter/Dart, FastAPI/Python, SQLite, OpenRouter. Проверены 42 теста сервера и 46 тестов приложения, узкие экраны и увеличение текста до 130%. Личные фотографии выдаются только участникам чата, API-ключ модели хранится на сервере.

Для демонстрации подготовлены 16 новостей и событий, 8 вымышленных профилей, 35 комментариев с ответами, демоконтакты, заявки и переписки. В некоторых событиях есть несколько изображений. Проект является прототипом хакатона и не представляет официальный сервис университета.

Файлы: `pulse-online.apk` — основная версия с настоящей ИИ-проверкой; `pulse-demo.apk` — автономная версия; `pulse-source.zip` — исходники без ключей, пользовательской базы и рабочих данных сервера. Сценарий проверки: `docs/REVIEW.md`.
