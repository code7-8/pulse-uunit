# Архитектура

Клиент Flutter обращается к REST API `/api`. Сервер FastAPI хранит данные в SQLite и медиа на диске. Пользовательские роли и переходы статусов проверяются сервером.

## Публикации

Состояния: `draft`, `pending`, `published`, `changes_requested`, `rejected`.

Публичная лента содержит только одобренные публикации. Автор видит свои материалы и причины решений. Модератор рассматривает очередь. Изменение одобренного материала требует новой проверки. Модератор оставляет причину при отказе или возврате на доработку. Решения записываются в историю.

## Обсуждения и профили

Публиковать комментарии и реакции может авторизованный пользователь. Удалять комментарий может его автор или модератор. Пользователь может отправить жалобу. Поля роли и счётчиков профиля не редактируются через пользовательский запрос.

## Предварительная проверка ИИ

После отправки материал получает статус проверки ИИ. Сервер передаёт текст и уменьшенные копии локальных фотографий DeepSeek V4.1 Flash 1017 через OpenRouter с сортировкой провайдеров по цене. Ключ хранится в закрытой папке рабочего сервера. При замечании автор может исправить публикацию или запросить перепроверку человеком. Публикация в общую ленту всегда требует решения модератора.

Результат привязан к версии материала. Поздний ответ ИИ не может отменить правки автора или решение человека. При ошибке сервиса материал остаётся в ручной очереди. Бюджет проверки — $1,60. Личные переписки и данные аккаунта не отправляются модели.

Публикация содержит до шести фотографий; первая используется как обложка. Есть счётчик, галерея и полноэкранный просмотр с увеличением. Подписки на темы хранятся в интересах профиля; лента «Подписки» объединяет выбранные темы и авторов без дублирования публикаций.

## Ограничения прототипа

SQLite и файловое хранилище рассчитаны на один экземпляр сервера. Для развёртывания на нескольких экземплярах потребуются общая СУБД и объектное хранилище. Демо-аккаунты и загрузку демонстрационных материалов следует отключить в публичном сервисе. Уведомления внутри приложения не заменяют push-уведомления.
