# Публичный сервер на ноутбуке

Сервер работает в текущем сеансе Windows. Отдельная учётная запись Windows не создавалась. Инструменты, настройки, база, фото, ключ туннеля, временные файлы, логи и резервные копии находятся внутри проекта.

## Запуск и остановка

- Запуск: `ЗАПУСТИТЬ_ИНТЕРНЕТ_СЕРВЕР.cmd`. Повторный запуск не создаёт второй сервер.
- Текущий адрес: `runtime/server/АДРЕС_СЕРВЕРА.txt` и `runtime/server/status.json`.
- APK для совместной работы: `artifacts/pulse-online.apk`. Установить поверх основной версии и создать свой профиль. Приложение само получает актуальное подключение.
- Доступ модератора: локальный файл `runtime/server/ДОСТУПЫ.txt`. Его нельзя отправлять вместе с APK. Прежние общие пароли заменены.
- Остановка: `ОСТАНОВИТЬ_ИНТЕРНЕТ_СЕРВЕР.cmd`.

Если бесплатный туннель сменит адрес, приложение проверит подписанную запись и подключится к новому адресу. При смене соединения может потребоваться обновить ленту через несколько секунд. Повторная установка APK и вход не нужны. «Пульс Демо» хранит данные на телефоне и к общему серверу не подключается.

Для обнаружения адреса используется бесплатная анонимная запись superjsonblob. В ней только публичный адрес, срок действия, идентификатор стенда и подпись Ed25519. Паролей, сессий, фотографий и данных пользователей там нет. Закрытый ключ хранится только в `runtime/server/identity.pem`, открытый ключ закреплён в APK. Приложение проверяет подпись записи и ответ сервера на случайный запрос до передачи учётных данных. Ответ привязан к текущему адресу, чтобы старый домен не мог выдать себя за сервер. Подмена записи не позволяет перенаправить сессию; удаление записи может временно нарушить обнаружение нового адреса. При недоступности каталога используется сохранённый адрес, если сервер подтвердил свою подлинность.

## Работа до финала

Для первого этапа включён `review_demo: true` в `runtime/server/settings.json`. В общей ленте 16 опубликованных примеров и 35 комментариев, есть вымышленные профили. Новый аккаунт получает двух демодрузей, одну входящую заявку, подписки на демоавторов и две начальные переписки с фотографией. Этот же набор один раз добавляется существующим аккаунтам. Профили обозначены как демонстрационные в описании. Действия с настоящими участниками работают через общую базу.

Это подготовленные примеры; автоматические ответы ботов в переписках не генерируются. После удаления демодруга или отклонения заявки они не восстанавливаются. Смена `review_demo` на `false` отключит наполнение новых аккаунтов после перезапуска сервера.

Нужны включённый ноутбук, питание и интернет. Пока работает диспетчер, он временно запрещает автоматический сон; план электропитания не меняется. Экран можно гасить и блокировать Windows. После ручной перезагрузки Windows нужно снова запустить командный файл.

Диспетчер перезапускает завершившиеся процессы API и туннеля. База копируется раз в час; остаются последние 24 копии в `runtime/server/backups`. Логи ограничены по размеру. После множества последовательных сбоев диспетчер останавливается, причина остаётся в журнале.

Стенд автоматически останавливается **27 октября 2026 в 00:00 по Уфе**, то есть после окончания 26-го. Время и квота фото находятся в `runtime/server/settings.json`.

## Доступ и ограничения

API слушает только `127.0.0.1:8000`. Публичные запросы приходят через HTTPS-туннель. Поддерживаются ngrok и временный SSH-туннель localhost.run. Порты роутера, удалённый рабочий стол и общие папки Windows для этого не открывались. Сам процесс имеет права текущего пользователя Windows; туннель не является песочницей.

Общие пароли демоаккаунтов заменены, их старые сессии отозваны. Документация API отключена. Исходники, настройки и база не раздаются по HTTP. Личные фотографии доступны только участникам переписки. У приложения нет маршрутов для файлового менеджера или выполнения команд.

Запросы ограничены по частоте, размеру, времени чтения и числу одновременных обработок. Фото проверяются, перекодируются и получают случайные имена. Общая квота фото — 1 ГБ, при свободном месте на диске меньше 1 ГБ загрузки отклоняются. Доступ к папке рабочего сервера ограничен текущим пользователем и SYSTEM.

Это временный стенд прототипа, полноценный аудит безопасности не проводился. Временный localhost.run меняет адрес даже без перезапуска; приложение учитывает это автоматически. Ни туннель, ни бесплатный каталог не дают гарантии доступности. Более ранняя проверка с телефона через мобильную сеть прошла успешно.

## Данные и проверка

Рабочая база: `runtime/server/data/pulse.sqlite3`. При первой подготовке она копируется из локальной базы с сохранением содержимого. Исходная `backend/data/pulse.sqlite3` остаётся неизменной. Дальше базы независимы, действия телефонов записываются в публичную базу.

`scripts/Check-PublicServer.py` проверяет настоящий HTTPS-сценарий: публикация, возврат, исправление, одобрение, реакции, комментарии, дружба, переписка и приватность фото. Созданные тестовые данные удаляются. Отчёт: `runtime/server/https-check.json`.

Сборка с текущим адресом и закреплённой публичной идентичностью: `scripts/Build-Android.ps1 -PublicServer`. Для ARM64 добавить `-Arm64`. Не удалять `identity.pem`, `instance.txt` и `discovery.json`: они связывают уже установленные APK с этим сервером.

Документация туннеля: https://localhost.run/docs/ и https://localhost.run/docs/faq/ . Cloudflare тоже подготовлен как альтернатива (`provider: cloudflare`), но в текущей сети проверка его соединения не прошла.

## Подключение бесплатного ngrok

1. Войти в бесплатный аккаунт на https://dashboard.ngrok.com/signup . Для HTTP-туннеля платёжные данные не нужны.
2. Открыть https://dashboard.ngrok.com/get-started/your-authtoken .
3. Запустить `ПОДКЛЮЧИТЬ_NGROK.cmd` и вставить только токен. Ввод скрыт. Конфигурация создаётся в `runtime/server/ngrok.yml`, без изменения профиля Windows и без записи токена в аргументы процесса.
4. Перезапустить публичный сервер, дождаться нового адреса в status.json, выполнить HTTPS-проверку и собрать APK с `-PublicServer`.

У ngrok отключены инспектор запросов и удалённое управление агентом. Бесплатный тариф имеет ограничения: https://ngrok.com/docs/pricing-limits/free-plan-limits . Приложение приостанавливает опрос списка чатов, когда свёрнуто или поверх него открыта переписка.

## Проверка публикаций ИИ

DeepSeek V4.1 Flash 1017 работает через OpenRouter. Ключ — `runtime/server/openrouter.key`, вводится через `ПОДКЛЮЧИТЬ_OPENROUTER.cmd`. Он не включается в APK, архив исходников и HTTP-ответы. Лимит в `settings.json`: `ai_budget_usd: 1.6`. При недоступности API и исчерпании лимита остаётся ручная проверка.

Автор сразу видит «На проверке ИИ», затем объяснение результата. ИИ проверяет текст и до шести уменьшенных изображений, не скачивает произвольные внешние URL. Автор может обжаловать замечание человеку. Автоматическая проверка не публикует материал самостоятельно.

Запуск фона отделён от процесса Codex средствами Windows, чтобы прерывание команды в чате не останавливало сервер. Отдельная учётная запись Windows и задания автозапуска не создавались.
