# Пульс Демо

Отдельная сборка для проверки интерфейса без ноутбука, сервера и интернета. Пакет `ru.uunit.pulse.demo` устанавливается рядом с основной версией. У Android-приложения нет разрешения INTERNET.

В комплект входят 16 опубликованных новостей и событий, два материала автора для проверки редакции, 8 профилей, 35 комментариев с ответами, примеры дружбы и переписок, фотографии. При первом запуске даты примеров смещаются относительно текущего времени, чтобы события оставались актуальными. Сразу открыт демо-профиль студента.

Новый зарегистрированный демоаккаунт тоже получает двух демодрузей, входящую заявку, подписки и две переписки, в одной из которых уже есть фотография. Набор добавляется один раз: удалённые контакты не восстанавливаются при следующем запуске. Демо-профили отмечены в описании.

Лайки, комментарии, отметки участия, друзья, сообщения, фотографии и свои публикации сохраняются локально. У каждого телефона своя копия данных: переписка и изменения между устройствами не передаются.

Для проверки модерации нужно отправить материал от студента, выйти из профиля, на экране входа выбрать «Демо-доступ → Модератор» и рассмотреть заявку. Решения и исправления тоже хранятся на телефоне.

Сборка: `scripts/Build-Demo.ps1`. Компактный вариант для ARM64: добавить `-Arm64`. Удаление данных приложения через настройки Android возвращает исходные примеры.

Обновление исходного набора: `backend/.venv/Scripts/python.exe scripts/Refresh-DemoSeed.py`. Скрипт создаёт новую временную базу с вымышленными примерами; реальные аккаунты, сессии и серверные хеши паролей в APK не попадают.
