# Пульс

Android-приложение для новостей, мероприятий и общения студентов УУНИТ. Проект хакатона по кейсу «Умное решение для ленты новостей».

## Скачать готовое приложение

- **[Пульс — основная версия с ИИ-проверкой](https://github.com/code7-8/pulse-uunit/releases/download/v1.1.0/pulse-online.apk)**
- **[Пульс Демо — без интернета и сервера](https://github.com/code7-8/pulse-uunit/releases/download/v1.1.0/pulse-demo.apk)**
- [Все файлы релиза](https://github.com/code7-8/pulse-uunit/releases/tag/v1.1.0)

Скачайте APK на Android и установите. Собирать проект самостоятельно не требуется. Основная версия подключается к общей базе: создайте свой профиль. Демоверсия сразу открывает готовый профиль и хранит изменения на телефоне. Приложения устанавливаются рядом.

В приложении есть подписки на темы и авторов, друзья, комментарии с ответами, чаты с фото, галереи до шести снимков и темы оформления. В основной версии DeepSeek 1017 предварительно проверяет публикации; окончательное решение принимает человек.
